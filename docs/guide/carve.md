# Carve

Carve support lives in its own plugin, [cakephp-carve](https://github.com/markup-carve/cakephp-carve). It covers rendering, `.crv` templates, validation, an ORM behavior, commands and caching, and requires [markup-carve/carve-php](https://github.com/markup-carve/carve-php) with a version constraint.

```sh
composer require markup-carve/cakephp-carve
```

See its README for setup and usage.
